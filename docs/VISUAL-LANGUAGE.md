# Visual Language

## Target

Meowcore is a bold 2D cartoon rendered through Live2D, not an anime character that happens to have thick lines.

## Rules

- Prefer strong, simple silhouettes over intricate detail.
- Keep outer contours visually dominant and easy to read at stream-overlay scale.
- Use flat or minimally shaded color blocks unless shading serves form/readability.
- Facial features should remain graphic and intentional rather than realistic.
- Expressions may exaggerate proportion, spacing and pose.
- Decorative physics are optional; constant floating motion is not a default requirement.
- The model should look good when held still on a strong pose.

## Design tests

Before accepting a design direction, check:

1. black-silhouette recognition,
2. thumbnail-scale readability,
3. neutral/front pose clarity,
4. extreme reaction readability,
5. outline continuity under expected motion ranges.

## Avoid

- generic anime-VTuber convergence,
- over-rendered gradients that weaken shape readability,
- excessive pseudo-3D deformation,
- detail that disappears at broadcast size,
- motion/physics added only because Live2D supports it.
