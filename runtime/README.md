# Avatar Runtime

This directory is reserved for the host-served Meowcore Avatar Runtime implementation.

The canonical boundary is defined in `docs/ARCHITECTURE.md`:

- runtime executes as an independent Ubuntu-host service,
- Hermes is an engineering/validation client,
- H4V3-DJ is a future production client,
- Cubism Editor remains a human GUI authoring surface.

The first implementation task is `.agent/pr-requests/PR-001-avatar-runtime-bootstrap.md`.
